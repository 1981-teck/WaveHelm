Source code and licenses

This page identifies the official public source repository for WaveHelm and explains where users can find project and third-party license information.

Official source repository

The official public source repository for WaveHelm is:

https://github.com/1981-teck/WaveHelm

This repository is the correct public reference for source code, project documentation, screenshots, and public legal/license files.

Runtime notices in the application

Installed builds of WaveHelm are expected to expose a runtime-accessible notices bundle from within the application. That runtime bundle is the correct in-app source for third-party notices and legal material that must remain visible to end users of a packaged build.

This public website does not replace the runtime notices bundle inside the app.
