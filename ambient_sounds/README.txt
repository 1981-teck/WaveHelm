This directory is intentionally kept as a user-provided ambient library placeholder for the public source repository.

No third-party ambient audio files are shipped in the public GitHub snapshot.

How to use this directory:
- add your own ambient audio files here
- supported formats include .wav, .mp3, .flac, .ogg, .m4a, .aac, .opus, and .wma
- WaveHelm will pick up available files from this folder when running from source

If you publish your own build or derivative, make sure every bundled ambient asset is redistributable under terms that are compatible with your distribution model.
