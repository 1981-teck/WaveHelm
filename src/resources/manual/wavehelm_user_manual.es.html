Manual de usuario de WaveHelm

WaveHelm · versión 1.0 · reproductor multimedia de escritorio para Windows

WaveHelm es un reproductor multimedia para Windows orientado a una reproducción ágil, gestión de medios locales, herramientas de procesamiento de audio, reproducción ambiental y una ruta de vídeo basada en Media Foundation. Este manual describe las funciones mantenidas en la interfaz wx actual.

Resumen rápido

WaveHelm reúne reproducción local de audio y vídeo, biblioteca persistente, listas de reproducción, favoritos, ecualizador, efectos DSP, reproducción ambiental, visualizador en tiempo real, herramientas de mantenimiento y un manual integrado localizado. La compilación actual está diseñada para Windows y usa una ventana de vídeo externa para la reproducción de vídeo.

Secciones principales de la aplicación

  • Biblioteca: importa archivos o carpetas, busca en el catálogo, filtra por tipo de medio, ordena entradas, inicia la reproducción, añade elementos seleccionados a favoritos, elimina elementos de la biblioteca y mantiene resaltada la fila del archivo en reproducción.
  • Playlist: crea o elimina listas, añade archivos o carpetas a la lista seleccionada, elimina pistas seleccionadas, reabre colecciones guardadas, recuerda el ancho de las columnas y resalta la pista en reproducción.
  • Favoritos: reabre rápidamente los elementos guardados, elimina favoritos seleccionados, actualiza la vista, selecciona todos los favoritos visibles y mantiene resaltada la fila activa.
  • Ecualizador: activa o desactiva el EQ, ajusta las bandas disponibles, selecciona presets integrados, guarda o elimina presets personalizados, restablece la curva Flat y abre la carpeta de audio procesado.
  • Efectos: configura eco, reverberación y filtro vintage, guarda la configuración actual de efectos, restablece todos los efectos, exporta la sesión de audio procesada a WAV y abre directamente la carpeta de exportación.
  • Visualizer: inicia o detiene el espectro, elige el número de bandas, usa el gráfico integrado, abre una ventana visualizer separada y pone esa ventana en pantalla completa con F11.
  • Ambient: actualiza la biblioteca ambient, abre la carpeta ambient, selecciona un archivo ambiental, lo reproduce o detiene de forma independiente a la cola principal, ajusta el volumen ambient, silencia la capa ambient y guarda la mezcla en WAV.
  • Configuración: cambia idioma, tema y volumen general; elige pista de audio y subtítulos del vídeo cuando la sesión activa los expone; abre carpetas runtime; y ejecuta acciones de mantenimiento.
  • Readmi: abre el manual integrado en el idioma actual y con el tema activo.
  • About: muestra identidad del producto, módulos habilitados, bibliotecas usadas, contacto y exporta los metadatos de la aplicación en JSON.

Inicio rápido

  1. Abre Biblioteca e importa uno o más archivos o carpetas locales.
  2. Selecciona un elemento e inicia la reproducción.
  3. Usa el mini-player del pie para reproducir, pausar, detener, ir al anterior, siguiente, buscar, activar shuffle, loop, mute y volumen.
  4. Abre Ecualizador, Efectos o Ambient para moldear la sesión.
  5. Abre Visualizer si quieres una vista de espectro en vivo o una ventana separada en pantalla completa.
  6. Abre Configuración para idioma, tema, pistas de vídeo, carpetas y mantenimiento.

Mini-player y comportamiento de la reproducción

El mini-player del pie permanece disponible en toda la shell wx mantenida. Muestra el título actual, el estado de reproducción, la barra de progreso, el tiempo transcurrido, la duración total y los controles principales de transporte.

  • Reproducir, pausa, detener, anterior, siguiente: controles estándar para la cola actual.
  • Seek: arrastra o pulsa la barra de progreso para moverte por el elemento actual.
  • Shuffle y loop: activan reproducción aleatoria o repetida.
  • Volumen y mute: ajustan la salida general desde el mini-player o desde Configuración.
  • Cambio rápido: WaveHelm está diseñado para alternar con rapidez entre audio y vídeo dentro de la misma sesión.

Biblioteca, playlists y favoritos

La capa de persistencia guarda las referencias a los medios importados y te permite reabrir tu catálogo entre sesiones.

  • La página Biblioteca admite búsqueda, ordenación, filtrado por tipo de medio, reproducción directa, acciones de añadir a favoritos, eliminación de la biblioteca y memoria del ancho de columnas.
  • La página Playlist separa la gestión de listas de la gestión de pistas, para que puedas mantener colecciones con nombre a lo largo del tiempo, con botones para añadir archivos individuales o carpetas completas a la lista seleccionada.
  • La página Favoritos está pensada para acceso rápido a medios seleccionados sin volver a buscar en todo el catálogo e incluye una acción de seleccionar todo.
  • Biblioteca, Playlist y Favoritos pueden resaltar con un color dedicado la fila del archivo en reproducción para que el elemento activo siga visible incluso después de cambios de navegación.

Ecualizador, efectos y audio procesado

  • La página Ecualizador expone el flujo mantenido de bandas y presets. Los presets personalizados pueden guardarse y eliminarse desde la misma página.
  • Al reiniciar la aplicación, el preset inicial del ecualizador vuelve intencionadamente a Flat en lugar de restaurar el nombre del último preset seleccionado.
  • La página Ecualizador también puede abrir la carpeta processed_audio usada por los assets de reproducción renderizados mediante DSP.
  • La página Efectos cubre actualmente eco, reverberación y filtro vintage.
  • Una acción Guardar ajustes conserva la configuración actual de efectos, mientras que Restablecer todos los efectos devuelve el estado base mantenido.
  • El botón Guardar audio de la página Efectos exporta la pista de audio actual con los efectos activos aplicados a un archivo .wav.
  • El botón adyacente Abrir carpeta guardada abre directamente la carpeta predeterminada %APPDATA%\WaveHelm\effects saved.

Visualizer

  • El visualizer puede funcionar dentro de la página o en una ventana externa separada.
  • Puedes cambiar el número de bandas del espectro desde los controles del visualizer.
  • La ventana separada admite modo de pantalla completa mediante botón dedicado o tecla F11.
  • Si el backend gráfico preferido no está disponible, WaveHelm usa un renderizador de compatibilidad más simple en lugar de dejar la página vacía.

Reproducción ambiental

La sección ambient está separada de la cola principal. Puedes mantener activo un sonido ambiental, un archivo hablado o una superposición musical de forma independiente a la pista principal cuando tu flujo de trabajo lo requiera.

  • Usa Actualizar para reconstruir la lista ambient después de añadir o quitar archivos de la carpeta ambient.
  • Usa Abrir carpeta para ir directamente al directorio origen de los archivos ambient.
  • La reproducción ambient tiene su propio control de volumen y su propio interruptor de mute.
  • Guardar mezcla exporta la sesión actual más la superposición ambient seleccionada a un archivo .wav.
  • Abrir carpeta de mezcla abre directamente la carpeta predeterminada %APPDATA%\WaveHelm\ambient mix saved.

Comportamiento del vídeo y selección de pistas

  • La compilación actual usa una ventana de vídeo externa para la reproducción de vídeo.
  • La reproducción de vídeo depende de la pila Windows Media Foundation y de la integración COM relacionada.
  • Los selectores de pista de audio de vídeo y pista de subtítulos están en Configuración y se rellenan cuando la sesión activa expone opciones compatibles.
  • Si un vídeo se abre pero no tiene sonido audible, comprueba primero el códec y prioriza AAC cuando se necesite compatibilidad amplia.

Configuración, mantenimiento y About

La página Configuración centraliza preferencias del usuario, carpetas runtime y acciones de mantenimiento.

  • Cambia idioma y tema.
  • Ajusta el volumen general persistente.
  • Abre la carpeta de datos de la aplicación, la carpeta processed audio, los logs y el paquete de avisos/licencias de terceros.
  • Limpia la caché de audio procesado cuando ninguna sesión de audio activa la esté usando.
  • Solicita limpieza de artefactos runtime generales como caché y contenido de logs.
  • La página About enumera versión, autor, licencia, plataforma objetivo, sitio web, módulos habilitados, bibliotecas usadas e información de contacto.
  • La página About puede exportar metadatos a %APPDATA%\WaveHelm\exports\wavehelm_app_info.json.

Persistencia de datos y carpetas runtime

En Windows, WaveHelm guarda los datos runtime bajo %APPDATA%\WaveHelm.

  • settings.json guarda la configuración del usuario.
  • wavehelm.db guarda los datos SQLite usados por biblioteca, playlists, favoritos, presets y estado runtime relacionado.
  • logs\wavehelm.log guarda los logs de la aplicación.
  • processed_audio\ guarda archivos de caché renderizados mediante DSP.
  • ambient mix saved\ guarda archivos WAV exportados desde la página Ambient.
  • effects saved\ guarda archivos WAV exportados desde la página Efectos.
  • exports\wavehelm_app_info.json guarda los metadatos exportados desde la página About.
  • licenses\ guarda el paquete runtime de avisos/licencias de terceros.

Configuración, playlists, favoritos, presets EQ personalizados, volumen general y anchos de columna están pensados para persistir entre sesiones.

Formatos compatibles y límites actuales

  • WaveHelm funciona mejor con medios que la instalación actual de Windows puede decodificar mediante Media Foundation.
  • La compilación actual no incluye un decodificador interno para audio AC-3, E-AC-3 o TrueHD.
  • AAC sigue siendo la opción más fiable para una compatibilidad amplia en esta compilación.
  • ffprobe, cuando está disponible en el PATH, puede mejorar algunas rutas de detección de duración y metadatos.

Notas operativas

  • WaveHelm está orientado a Windows y la rama de vídeo depende de componentes de Windows.
  • La interfaz wx es el runtime UI mantenido.
  • La página Readmi está localizada y sigue el tema activo, por eso los archivos del manual se mantienen separados del README en la raíz del repositorio.
