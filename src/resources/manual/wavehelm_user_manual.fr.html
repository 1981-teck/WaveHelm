Manuel utilisateur WaveHelm

WaveHelm · version 1.0 · lecteur multimédia de bureau pour Windows

WaveHelm est un lecteur multimédia pour Windows orienté vers une lecture réactive, la gestion des médias locaux, les outils de traitement audio, la lecture ambient et une chaîne vidéo basée sur Media Foundation. Ce manuel décrit les fonctions maintenues par l'interface wx actuelle.

Vue d'ensemble

WaveHelm réunit lecture audio et vidéo locale, bibliothèque persistante, playlists, favoris, égaliseur, effets DSP, lecture ambient, visualiseur temps réel, outils de maintenance et manuel intégré localisé. La build actuelle est conçue pour Windows et utilise une fenêtre vidéo externe pour la lecture vidéo.

Sections principales de l'application

  • Bibliothèque : importe des fichiers ou des dossiers, recherche dans le catalogue, filtre par type de média, trie les entrées, lance la lecture, ajoute les éléments sélectionnés aux favoris, supprime des éléments de la bibliothèque et garde la ligne du fichier en cours de lecture mise en évidence.
  • Playlist : crée ou supprime des playlists, ajoute des fichiers ou des dossiers à la playlist sélectionnée, supprime les pistes choisies, rouvre des collections enregistrées, mémorise la largeur des colonnes et met en évidence la piste en cours de lecture.
  • Favoris : rouvre rapidement les éléments enregistrés, supprime les favoris sélectionnés, actualise la vue, sélectionne tous les favoris visibles et garde la ligne active mise en évidence.
  • Égaliseur : active ou désactive l'EQ, ajuste les bandes disponibles, sélectionne des presets intégrés, enregistre ou supprime des presets personnalisés, rétablit la courbe Flat et ouvre le dossier d'audio traité.
  • Effets : configure l'écho, la réverbération et le filtre vintage, enregistre la configuration actuelle des effets, réinitialise tous les effets, exporte la session audio traitée en WAV et ouvre directement le dossier d'export.
  • Visualizer : démarre ou arrête le spectre, choisit le nombre de bandes, utilise le graphique intégré, ouvre une fenêtre visualizer détachée et place cette fenêtre en plein écran avec F11.
  • Ambient : actualise la bibliothèque ambient, ouvre le dossier ambient, sélectionne un fichier ambient, le lit ou l'arrête indépendamment de la file principale, ajuste le volume ambient, coupe le son de la couche ambient et enregistre le mix en WAV.
  • Paramètres : change la langue, le thème et le volume général ; choisit la piste audio et les sous-titres vidéo quand la session active les expose ; ouvre les dossiers runtime ; et exécute les actions de maintenance.
  • Readmi : ouvre le manuel intégré dans la langue courante et avec le thème actif.
  • About : affiche l'identité du produit, les modules activés, les bibliothèques utilisées, les contacts et exporte les métadonnées de l'application en JSON.

Démarrage rapide

  1. Ouvre Bibliothèque et importe un ou plusieurs fichiers ou dossiers locaux.
  2. Sélectionne un élément et démarre la lecture.
  3. Utilise le mini-player du pied de page pour lecture, pause, arrêt, précédent, suivant, seek, shuffle, loop, mute et volume.
  4. Ouvre Égaliseur, Effets ou Ambient pour modeler la session.
  5. Ouvre Visualizer si tu veux une vue spectrale en direct ou une fenêtre détachée en plein écran.
  6. Ouvre Paramètres pour la langue, le thème, les pistes vidéo, les dossiers et la maintenance.

Mini-player et comportement de lecture

Le mini-player du pied de page reste disponible dans toute la shell wx maintenue. Il affiche le titre courant, l'état de lecture, la barre de progression, le temps écoulé, la durée totale et les contrôles de transport principaux.

  • Lecture, pause, arrêt, précédent, suivant : contrôles standard pour la file courante.
  • Seek : fais glisser ou clique sur la barre de progression pour te déplacer dans l'élément courant.
  • Shuffle et loop : activent la lecture aléatoire ou répétée.
  • Volume et mute : règlent la sortie générale depuis le mini-player ou la page Paramètres.
  • Changement rapide : WaveHelm est conçu pour passer rapidement entre éléments audio et vidéo au cours de la même session.

Bibliothèque, playlists et favoris

La couche de persistance enregistre les références des médias importés et permet de rouvrir le catalogue entre les sessions.

  • La page Bibliothèque prend en charge la recherche, le tri, le filtrage par type de média, la lecture directe, l'ajout aux favoris, la suppression depuis la bibliothèque et la mémorisation de la largeur des colonnes.
  • La page Playlist sépare la gestion des playlists et des pistes, afin de maintenir des collections nommées dans le temps, avec des boutons pour ajouter des fichiers individuels ou des dossiers entiers à la playlist sélectionnée.
  • La page Favoris est destinée à l'accès rapide aux médias sélectionnés sans refaire une recherche dans tout le catalogue et inclut une action de sélection globale.
  • Bibliothèque, Playlist et Favoris peuvent mettre en évidence avec une couleur dédiée la ligne du fichier en cours de lecture, afin que l'élément actif reste visible même après des changements de navigation.

Égaliseur, effets et audio traité

  • La page Égaliseur expose le flux maintenu des bandes et des presets. Les presets personnalisés peuvent être enregistrés et supprimés depuis la même page.
  • Au redémarrage de l'application, le preset de démarrage de l'égaliseur revient volontairement sur Flat au lieu de restaurer le nom du dernier preset sélectionné.
  • La page Égaliseur peut aussi ouvrir le dossier processed_audio utilisé par les assets de lecture rendus via DSP.
  • La page Effets couvre actuellement l'écho, la réverbération et le filtre vintage.
  • Une action Enregistrer les réglages conserve la configuration actuelle des effets, tandis que Réinitialiser tous les effets restaure l'état de base maintenu.
  • Le bouton Enregistrer l'audio de la page Effets exporte la piste audio courante avec les effets actifs appliqués dans un fichier .wav.
  • Le bouton adjacent Ouvrir le dossier enregistré ouvre directement le dossier par défaut %APPDATA%\WaveHelm\effects saved.

Visualizer

  • Le visualizer peut fonctionner dans la page ou dans une fenêtre externe détachée.
  • Tu peux changer le nombre de bandes du spectre depuis les contrôles du visualizer.
  • La fenêtre détachée prend en charge le mode plein écran via le bouton dédié ou la touche F11.
  • Si le backend graphique préféré n'est pas disponible, WaveHelm utilise un rendu de compatibilité plus simple au lieu de laisser la page vide.

Lecture ambient

La section ambient est séparée de la file principale. Tu peux garder actif un son ambient, un fichier parlé ou une superposition musicale indépendamment de la piste principale quand ton flux de travail l'exige.

  • Utilise Actualiser pour reconstruire la liste ambient après avoir ajouté ou supprimé des fichiers dans le dossier ambient.
  • Utilise Ouvrir le dossier pour accéder directement au répertoire source des fichiers ambient.
  • La lecture ambient dispose de son propre contrôle de volume et de son propre interrupteur mute.
  • Enregistrer le mix exporte la session courante plus la superposition ambient sélectionnée dans un fichier .wav.
  • Ouvrir le dossier du mix ouvre directement le dossier par défaut %APPDATA%\WaveHelm\ambient mix saved.

Comportement vidéo et sélection des pistes

  • La build actuelle utilise une fenêtre vidéo externe pour la lecture vidéo.
  • La lecture vidéo dépend de la pile Windows Media Foundation et de l'intégration COM associée.
  • Les sélecteurs de piste audio vidéo et de piste de sous-titres se trouvent dans Paramètres et se remplissent lorsque la session active expose des options compatibles.
  • Si une vidéo s'ouvre sans son audible, vérifie d'abord le codec et privilégie AAC quand une compatibilité large est nécessaire.

Paramètres, maintenance et About

La page Paramètres centralise les préférences utilisateur, les dossiers runtime et les actions de maintenance.

  • Change la langue et le thème.
  • Ajuste le volume général persistant.
  • Ouvre le dossier de données de l'application, le dossier processed audio, les logs et le bundle des avis/licences tiers.
  • Nettoie le cache audio traité lorsqu'aucune session audio active ne l'utilise.
  • Demande le nettoyage des artefacts runtime généraux comme le cache et le contenu des logs.
  • La page About liste la version, l'auteur, la licence, la plateforme cible, le site web, les modules activés, les bibliothèques utilisées et les informations de contact.
  • La page About peut exporter les métadonnées vers %APPDATA%\WaveHelm\exports\wavehelm_app_info.json.

Persistance des données et dossiers runtime

Sous Windows, WaveHelm enregistre les données runtime sous %APPDATA%\WaveHelm.

  • settings.json enregistre les paramètres utilisateur.
  • wavehelm.db enregistre les données SQLite utilisées par la bibliothèque, les playlists, les favoris, les presets et l'état runtime associé.
  • logs\wavehelm.log enregistre les journaux de l'application.
  • processed_audio\ enregistre les fichiers de cache rendus via DSP.
  • ambient mix saved\ enregistre les fichiers WAV exportés depuis la page Ambient.
  • effects saved\ enregistre les fichiers WAV exportés depuis la page Effets.
  • exports\wavehelm_app_info.json enregistre les métadonnées exportées depuis la page About.
  • licenses\ enregistre le bundle runtime des avis/licences de tiers.

Les paramètres, playlists, favoris, presets EQ personnalisés, volume général et largeurs de colonnes sont destinés à persister entre les sessions.

Formats pris en charge et limites actuelles

  • WaveHelm fonctionne au mieux avec les médias que l'installation Windows actuelle peut décoder via Media Foundation.
  • La build actuelle n'inclut pas de décodeur interne pour l'audio AC-3, E-AC-3 ou TrueHD.
  • AAC reste le choix le plus fiable pour une compatibilité large dans cette build.
  • ffprobe, lorsqu'il est disponible dans le PATH, peut améliorer certains chemins de détection de durée et de métadonnées.

Notes opérationnelles

  • WaveHelm est orienté Windows et la branche vidéo dépend de composants Windows.
  • L'interface wx est le runtime UI maintenu.
  • La page Readmi est localisée et suit le thème actif, c'est pourquoi les fichiers du manuel sont conservés séparément du README à la racine du dépôt.
