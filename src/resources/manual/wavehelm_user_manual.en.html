WaveHelm User Manual

WaveHelm · version 1.0.1 · Windows desktop media player

WaveHelm is a Windows media player focused on responsive playback, local media management, audio shaping tools, ambient playback, and a Media Foundation based video path. This manual describes the maintained functions exposed by the current wx interface.

At a glance

WaveHelm combines local audio and video playback with a persistent library, playlists, favorites, equalizer controls, DSP effects, ambient playback, a real-time visualizer, maintenance tools, and a localized in-app manual. The current build is designed for Windows and uses an external video window for video playback.

Main sections of the application

  • Library: import files or folders, search the catalog, filter by media type, sort entries, play the selection, add selected items to favorites, remove items from the library, and keep the currently playing row highlighted.
  • Playlist: create or delete playlists, add files or folders to the selected playlist, remove selected tracks, reopen saved collections, remember table column widths, and highlight the currently playing track.
  • Favorites: play saved items quickly, remove selected favorites, refresh the view, select all visible favorites, and keep the active row highlighted.
  • Equalizer: enable or disable EQ, adjust the available frequency bands, select built-in presets, save or delete custom presets, reset the curve to Flat, and open the processed audio folder.
  • Effects: configure echo, reverb, and vintage filter parameters, save the current effect settings, reset all effects, export the current processed audio session to WAV, and open the export folder directly from the page.
  • Visualizer: start or stop the spectrum display, choose the band count, use the embedded plot, open a detached visualizer window, and switch that detached window to fullscreen with F11.
  • Ambient: refresh the ambient library, open the ambient folder, select an ambient file, play or stop it independently from the main queue, adjust ambient volume, mute the ambient layer, export the mixed session to WAV, and open the mix folder.
  • Settings: change language, theme, and master volume; choose active video audio and subtitle tracks when a compatible video session is active; open app folders; and run maintenance cleanup actions.
  • Readmi: open the built-in user manual in the current language and theme.
  • About: review product identity, enabled modules, libraries used, contact information, and export application metadata to JSON.

Quick start

  1. Open Library and import one or more local files or folders.
  2. Select an item and start playback.
  3. Use the footer mini-player for play, pause, stop, previous, next, seek, shuffle, loop, mute, and volume.
  4. Open Equalizer, Effects, or Ambient to shape the session.
  5. Open Visualizer if you want a live spectrum view or a detached fullscreen visualizer window.
  6. Open Settings for language, theme, video track selection, folders, and maintenance tasks.

Mini-player and playback behavior

The footer mini-player stays available across the maintained wx shell. It exposes the current track title, playback state, progress bar, elapsed time, total duration, and the primary transport controls.

  • Play, pause, stop, previous, next: standard transport controls for the current queue.
  • Seek: drag or click the progress control to move through the current item.
  • Shuffle and loop: toggle randomized or repeated playback behavior.
  • Volume and mute: adjust the master output directly from the mini-player or the settings page.
  • Fast switching: WaveHelm is designed to move quickly between audio and video items in the same session.

Library, playlists, and favorites

The persistence layer stores imported media references and lets you reopen your catalog between sessions.

  • The Library page supports search, sorting, media-type filtering, direct playback, add-to-favorites actions, removal from the library, and remembered column widths.
  • The Playlist page separates playlist management from track management so you can maintain named collections over time, with buttons to add individual files or whole folders to the selected playlist.
  • The Favorites page is intended for fast access to selected media without searching the full catalog again and includes a select-all action for visible rows.
  • Library, Playlist, and Favorites can highlight the currently playing row with a dedicated color so the active item stays visible even after navigation changes.

Equalizer, effects, and processed audio

  • The Equalizer page exposes the maintained band controls and preset workflow. Custom presets can be saved and deleted from the page.
  • At application restart, the equalizer startup preset is intentionally reset to Flat instead of restoring the last selected preset name.
  • The Equalizer page can also open the processed_audio folder used by DSP-rendered playback assets.
  • The Effects page currently covers echo, reverb, and vintage filter controls.
  • A Save settings action stores the current effect configuration, while Reset all effects restores the maintained baseline state.
  • A Save audio button in the Effects page exports the current audio track with the active effects applied as a .wav file.
  • The adjacent Open saved folder button opens the default %APPDATA%\WaveHelm\effects saved folder directly.

Visualizer

  • The visualizer can run inside the page or in a detached external window.
  • You can change the number of displayed spectrum bands from the visualizer controls.
  • The detached window supports fullscreen mode with the dedicated button or F11.
  • If the preferred plotting backend is unavailable, WaveHelm falls back to a simpler compatibility renderer instead of leaving the page empty.

Ambient playback

The ambient section is separate from the main playback queue. You can keep an ambient sound, spoken-word file, or music overlay running independently from the main track when your workflow calls for it.

  • Use Refresh to rebuild the ambient list after adding or removing files from the ambient folder.
  • Use Open folder to jump directly to the ambient source directory.
  • Ambient playback has its own volume control and mute toggle.
  • Save mix exports the current session plus the selected ambient overlay to a .wav file.
  • Open mix folder opens the default %APPDATA%\WaveHelm\ambient mix saved folder directly.

Video behavior and track selection

  • The current build uses an external video window for video playback.
  • Video playback depends on the Windows Media Foundation stack and related COM integration.
  • The active video audio track and subtitle track selectors are available in Settings and populate when the active session exposes compatible options.
  • If a video opens but has no audible sound, verify the codec first and prefer AAC when broad compatibility is required.

Settings, maintenance, and About

The settings page centralizes user preferences, runtime folders, and maintenance actions.

  • Change the current language and theme.
  • Adjust the persistent master volume.
  • Open the app data folder, processed audio folder, logs, and third-party notices.
  • Clear the processed audio cache when no active audio session is using it.
  • Request cleanup of general runtime artifacts such as cache and log content.
  • The About page lists version, author, license, target platform, website, enabled modules, libraries used, and contact information.
  • The About page can export metadata to %APPDATA%\WaveHelm\exports\wavehelm_app_info.json.

Data persistence and runtime folders

On Windows, WaveHelm stores runtime data under %APPDATA%\WaveHelm.

  • settings.json stores user settings.
  • wavehelm.db stores the SQLite data used for library, playlists, favorites, presets, and related runtime state.
  • logs\wavehelm.log stores application logs.
  • processed_audio\ stores DSP-rendered playback cache files.
  • ambient mix saved\ stores WAV files exported from the Ambient page.
  • effects saved\ stores WAV files exported from the Effects page.
  • exports\wavehelm_app_info.json stores metadata exported from the About page.
  • licenses\ stores the runtime third-party notices bundle.

Settings, playlists, favorites, custom EQ presets, master volume, and table column widths are intended to persist across sessions.

Supported formats and current limits

  • WaveHelm works best with media that the current Windows installation can decode through Media Foundation.
  • The current build does not include an internal decoder for AC-3, E-AC-3, or TrueHD.
  • AAC remains the most reliable choice for broad compatibility in this build.
  • ffprobe, when available in PATH, can improve some duration and metadata probing paths.

Operational notes

  • WaveHelm is a Windows-oriented product and the video branch depends on Windows components.
  • The wx interface is the maintained UI runtime.
  • The Readmi page is localized and theme-aware, so its resource files are stored separately from the repository root README.
